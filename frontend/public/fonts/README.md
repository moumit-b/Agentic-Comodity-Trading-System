# Fonts Directory

## Required Font

**Azeret Mono** (Variable Font)

### Download
Visit: https://fonts.google.com/specimen/Azeret+Mono

### Installation
1. Download the font family
2. Extract `AzeretMono-Variable.woff2`
3. Place it in this directory

### Fallback
If the font is not available, the application will use:
- `Courier New` (fallback monospace font)
- System monospace fonts

The application will work fine without the custom font, but the intended aesthetic uses Azeret Mono for all numerical data (prices, quantities, percentages).
